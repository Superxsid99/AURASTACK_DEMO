4.  Intake  Management  &  Routing  Logic  
Workflow  
Aurastack  uses  a  "Dispatcher"  pattern  to  manage  intake  through  the  Omnichannel  Intake  &  
Routing
 
(omnichannel_routing_v1)
 
workflow.
 
 
Processing  Steps  
●  Classification  
As
 
soon
 
as
 
a
 
message
 
arrives,
 
the
 
Aura
 
Intake
 
AI
 
analyzes
 
the
 
text.
 ●  Intent  Mapping  
The
 
AI
 
maps
 
the
 
request
 
to
 
a
 
specific
 
IntakeType:
 ○  CLAIM  →  Routes  to  Claims  Management  ○  QUOTE  →  Routes  to  Policy  Issuance  ○  HOSPITAL_INTAKE  →  Routes  to  Hospital  Exchange  ○  KYC  →  Routes  to  Patient  Onboarding  ●  Entity  Extraction  
The
 
AI
 
pre-fills
 
the
 
case
 
metadata
 
(e.g.,
 
extracting
 
the
 
claimant's
 
name
 
and
 
policy
 
ID)
 
so
 
the
 
agent
 
doesn't
 
have
 
to
 
type
 
it
 
manually.
 ●  Conversion  
When
 
the
 
agent
 
clicks
 
"Resolve
 
&
 
Trigger,"
 
the
 
system:
 ○  Creates  a  new  Case.  ○  Links  the  conversation  history  to  that  Case.  ○  Starts  the  target  workflow  at  the  start  node,  passing  all  extracted  metadata  into  
the
 
execution
 
context.
