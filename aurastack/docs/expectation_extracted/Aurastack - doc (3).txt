Overview  
The  Aurastack  platform  is  powered  by  a  fleet  of  11  specialized  AI  Agents,  each  designed  with  a  
specific
 
"Intelligence
 
Profile"
 
to
 
handle
 
different
 
stages
 
of
 
the
 
insurance
 
lifecycle.
 
Unlike
 
generic
 
LLMs,
 
these
 
agents
 
are
 
constrained
 
by
 
strict
 
schemas
 
and
 
have
 
access
 
to
 
specialized
 
tools.
 
 
1.  Medical  Data  Extractor  (doc_ext_01)  
●  Type:  Document  Intelligence  ●  Role:  The  "Eyes"  of  the  claims  engine.  
Capability  
Uses  high-precision  OCR  and  NLP  to  parse  medical  invoices  and  clinical  reports.  
Key  Outputs  
●  Patient  Name  ●  Procedure  Codes  (CPT/ICD-10)  ●  Billing  Amounts  ●  Primary  Diagnosis  
Constraint  
Strict  HIPAA  compliance;  it  is  forbidden  from  extracting  data  that  isn't  explicitly  verified  in  the  
source
 
document.
 
 
2.  Healthcare  Fraud  Sentinel  (fraud_det_01)  
●  Type:  Fraud  &  Risk  Analysis  ●  Role:  The  "Security  Guard."

Capability  
Analyzes  claims  against  historical  patient  data  and  clinical  guidelines  to  find  "Upcoding"  (billing  
for
 
a
 
more
 
expensive
 
service
 
than
 
performed)
 
or
 
"Unbundling."
 
Tools  
Accesses  the  clinical_guidelines_db.  
Human  Hook  
Automatically  triggers  a  "Human  Override"  if  the  fraud  risk  score  exceeds  70/100.  
 
3.  Patient  Identity  Validator  (kyc_val_01)  
●  Type:  Compliance  ●  Role:  The  "Gatekeeper."  
Capability  
Verifies  the  authenticity  of  ID  documents  (Passports,  DLs)  and  cross-references  them  with  
insurance
 
card
 
scans.
 
Tools  
Integrated  with  ocr_engine  and  insurance_eligibility_api.  
Usage  
Primary  agent  for  the  KYC  &  Onboarding  workflow.  
 
4.  Clinical  Risk  Modeler  (risk_model)  
●  Type:  Validation  &  Prediction  ●  Role:  The  "Medical  Expert."  
Capability

5.  Policy  Servicing  Specialist  (policy_servicer_01)  
●  Type:  Compliance  /  Admin  ●  Role:  The  "Account  Manager."

Logic

needs

Underwriting.

The  "Agent  Anatomy"  
Every  agent  in  Aurastack  follows  a  strict  architectural  pattern:  
Input  Schema  
Defines  exactly  what  data  the  agent  needs  to  start  (e.g.,  document_url).  
System  Instructions  
The  "Personality"  and  "Expertise"  of  the  agent.  
Tools  
The  external  APIs  or  databases  the  agent  can  "call."  
Output  Schema  

--- PAGE 7 ---
The  structured  JSON  the  agent  must  produce  (e.g.,  risk_score:  number).  
Confidence  Score  
Every  agent  output  includes  a  confidence  level,  allowing  the  Workflow  Builder  to  route  
low-confidence
 
results
 
to
 
humans.
